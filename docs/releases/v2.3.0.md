- 减少网站视图的重复布局，切换页面时取消未完成的过渡动画。
- 保留正在输入的网址和光标位置，关闭通知触发的任务栏闪烁。
- Windows 的本地数据目录改为“消息中心”。升级时复制原有配置、消息记录和登录会话，旧数据目录保留，可供旧版回退。
