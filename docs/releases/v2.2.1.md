Website Controller 的首个 GitHub 公开版本，提供 Windows 和 macOS 安装包。

### 下载哪个文件

| 系统 | 文件 |
| --- | --- |
| Windows 10 / 11 x64 | `Website-Controller-2.2.1-x64-Setup.exe`，安装使用 |
| Windows 免安装 | `Website-Controller-2.2.1-x64-Portable.exe`，直接运行 |
| macOS Apple 芯片 | `Website-Controller-2.2.1-macOS-arm64.dmg` |
| macOS Intel | `Website-Controller-2.2.1-macOS-x64.dmg` |

macOS 同时提供 ZIP 包。`SHA256SUMS.txt` 用于核对下载文件。

### 这个版本做了什么

启动页面前先确认网络监听器已就绪，避免启动很快的网站偶发漏接首个接口响应。

- 多个网站放进同一个工作台，各自保留登录状态。
- 自动寻找未读计数接口，监听 WebSocket / SSE 推送，并保留页面角标与正文监听。
- 符合条件的未读接口约每 3 秒检查一次，连续到达的提醒会合并显示。
- 支持批量添加、500 个网站配置、快捷查找、深浅主题与减少动画。
- 更新字体、文字对比度和应用图标；增加 macOS 菜单与状态栏适配。

### 使用与升级

登录网站后先进入消息页，再设为起始页。发现结果可在“连接详情”中查看。自动识别仍在寻找来源时，可以点选未读角标补充规则。

Windows 从旧版升级前，请先从托盘退出。已有网站、登录会话和本地记录会继续使用。

Windows 安装包未做商业签名。macOS 包使用临时签名，未做 Apple 公证，首次打开可能受到系统限制。macOS 的自动构建与本地页面测试不能代替所有网站的账号实测。

500 是可保存的配置数，同时启用多少个网站取决于内存和网站本身的开销。实际提醒速度取决于网站更新机制、网络和登录状态。
